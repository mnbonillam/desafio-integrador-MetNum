Ejercicio 1 — Error absoluto, relativo y propagación

7.5 pts

Un ingeniero mide el lado de una placa cuadrada. Se calcula el error absoluto, el error relativo porcentual y la propagación del error al área.

Ejercicio 2 — Taylor, error y residuo de Lagrange

16.5 pts

Para f(x) = eˣ se construyen los polinomios de Taylor de grado 1 y 2 alrededor de a = 0 y se aproxima eˣ. También se calcula una cota mediante el residuo de Lagrange.

Ejercicio 3 — Síntesis integradora

6 pts + análisis

Péndulo simple: g = 4π²L/T². Se calcula el valor experimental, los errores y la propagación mediante derivadas parciales. Finalmente se usa Taylor de grado 1 en T alrededor de T = 2.

Fórmulas utilizadas

Ea = |xv − xa|
Er(%) = |xv − xa| / |xv| × 100
Pn(x) = Σ [ f⁽ᵏ⁾(a) / k! ] (x − a)ᵏ
Δy ≈ |f′(x)| Δx
Δy ≈ Σ |∂f/∂xi| Δxi
